# Use a file directly

Quill can fill an `.xlsx` or `.csv` file even when no spreadsheet app is open. It opens the file for you and writes each row as you speak.

**You need:** a spreadsheet file with its column names in the first rows.

## Open the file

**1. Click the folder icon** ![folder](images/icon-folder.png) at the top of the window.

*You'll see:* the Files panel slide in on the right.

**2. Click Open File.**

![The Files panel, before a file is chosen](images/side-panel-file.png)

**3. Pick your file** (`.xlsx` or `.csv`) and click **Open**.

*You'll see:* the file's name under **Active File**, and your columns listed in the main window.

**4. Click Start** ![start](images/icon-play.png) **and speak.**

Quill remembers the file. Next time, just click Start.

## Good to know

Quill writes into the program that has the file open (Excel, Numbers or LibreOffice), so you watch every row arrive.

If another program refuses a save, Quill keeps your rows and saves them as soon as the file is free.

## If something looks off

| You see | Do this |
|---|---|
| **No columns on this sheet** on the Start button | Open a sheet whose column names are in its first rows. |
| **File not connected** | Click the folder icon ![folder](images/icon-folder.png) and open a file. |
| Rows don't appear in your spreadsheet app | Check the file is open there, then click the refresh icon next to **Sheet** in the Files panel. |
