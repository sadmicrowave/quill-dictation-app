# Every icon and button

What each icon does, and where to find it.

## The toolbar

On a Mac these sit in the title bar. On Windows they sit in a toolbar above the Start button.

| Icon | Name | What it does |
|---|---|---|
| ![help](images/icon-help.png) | **Help** | Opens this help, on the page for where you are |
| ![undo](images/icon-undo.png) | **Undo** | Takes back the last Term Helper answer |
| ![folder](images/icon-folder.png) | **Files** | Opens the Files panel: choose a file, see which sheet is open |
| ![turn](images/icon-turn.png) | **Turn options** | Opens the panel for Next Row / Append To, layout and speech model |
| ![settings](images/icon-settings.png) | **Settings** | Opens Settings |
| ![mini](images/icon-mini.png) | **Mini view** | Shrinks the window; click again to come back |

## In the window

| Icon | Name | What it does |
|---|---|---|
| ![start](images/icon-play.png) | **Start** | Starts listening (it reads **Stop** while listening) |
| ![next](images/icon-next.png) | **Next Row** | Saves the row, like saying "next row" (shows while listening) |
| ![x](images/icon-x.png) | **Remove line** | Appears over a value in the grid: removes it from the row |
| ![info](images/icon-info.png) | **Info** | Rest the pointer on it to read how that column works |
| ![gear](images/icon-gear.png) | **File settings** | Headings row, starting row and layout for the open sheet |
| ![refresh](images/icon-refresh.png) | **Refresh** | Checks now which file and sheet are open |
| ![bug](images/icon-bug.png) | **Log** | Opens and closes the Log, a record of what happened |
| ![export](images/icon-export.png) | **Export** | Saves the Log as a text file (shows while the Log is open) |

## Pills and badges

| You see | It means |
|---|---|
| A **purple pill** | Understood and placed |
| A **grey pill** in the words | Waiting in the Term Helper |
| A **grey pill** in the grid | A number Quill filled in itself |
| A **red dot** on an icon | Something changed that you should look at: hover it |
| A **red !** in the mini view | Something went wrong: hover it |
