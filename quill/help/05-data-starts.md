# Where your data starts

Use this when Quill can't find your column names, or starts writing in the wrong place.

## Open the file settings

**1. Click the gear** ![gear](images/icon-gear.png) next to **Active File** in the Files panel.

*You'll see:* a small box with **Headings Row**, **Starting Row** and **Sheet Layout**. (The gear is grey until a file is connected.)

**2. Set Headings Row** to the row that holds your column names.

**Automatic** finds it for you.

**3. Set Starting Row** to where Quill may begin writing.

**Automatic** means the first empty row under the headings.

**4. Choose Sheet Layout.**

**By Columns** (the usual): column names run across the top, and each record is a row. **By Rows**: column names run down the first column, and each record is a column.

*You'll see:* with **By Rows**, the Log says *Column C* where it said *Row 4*.

## Good to know

These settings belong to one sheet of one file. Another sheet, or another file, has its own, and Quill remembers each.

Search needs the column names across the top.

## If something looks off

| You see | Do this |
|---|---|
| **No columns on this sheet** on the Start button | Set **Headings Row** to the row with your column names. Start comes back by itself. |
| Rows land under the wrong heading | Check **Sheet Layout** matches how your sheet is built. |
| Quill starts too far down | Set **Starting Row**, or clear the extra cells. |
